# 202609 Statistics — Student Repository Template

Template repository for the Fall 2026 (202609) Statistics course.
Create your own repository from this template with **Use this template → Create a new repository**.

## Structure

```
.
├── Homework/        # Homework submissions, one folder per due date (MMDD)
│   ├── 0919/
│   ├── 1003/
│   ├── 1031/
│   └── 1114/
└── IC/              # In-class exercises, one folder per class date (MMDD)
    ├── 0919/
    ├── 1003/
    ├── 1031/
    └── 1114/
```

## How to use

1. Create a new repository from this template.
2. Clone it to your computer.
3. Put each assignment in the matching date folder under `Homework/` or `IC/`.
4. Commit and push before the deadline.

The `.gitkeep` files only keep the empty folders in git; you can leave them or delete them once a folder has content.
